# LegalMente — 48 prompts listos para ChatGPT (Camino A)

Fuente: `docs/catalogo-48-temas.md` (los 48 temas, ya verificados contra el
inventario real de Facebook) + `docs/legalmente-marca-y-estilo.md` §3.1 (arquitectura
de trece bloques) y §3.3 (plantilla de máximas latinas).

**Cómo usarlos:** copia un bloque completo (todo el texto entre las líneas de
código) y pégalo tal cual en el generador de imágenes nativo de ChatGPT — nunca
en el conector @Canva. Formato 9:16 vertical, listo para redes. Cuando tengas las
imágenes, me las regresas y las conecto al catálogo (`content/*.json` para video,
`src/content/catalogo.ts` para la web).

Cada prompt ya trae resuelta la paleta de acento, el objeto de integración de marca
y la escena — no hace falta rellenar nada entre corchetes, ya está sustituido.

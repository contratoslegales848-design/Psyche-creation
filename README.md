# Psyche Creation — LegalMente

Motor automatizado de videos verticales de LegalMente con Remotion 4, React y TypeScript.

## Crear un video desde el teléfono

1. Edita `guion-actual.json` desde GitHub.
2. Guarda el cambio con **Commit changes**.
3. GitHub Actions validará el código y renderizará el video automáticamente.
4. Descarga `video-legalmente-mp4` desde la ejecución terminada.

## Comandos

- `npm run studio`: vista previa local.
- `npm run typecheck`: validación TypeScript.
- `npm run render`: render MP4.
- `npm run build`: validación seguida del render.
